# 求人応募フォーム入力補助（汎用ATS・公開版）

Tampermonkey向けの求人応募フォーム入力支援UserScriptです。HRMOSを中心に、複数のATSでフォーム項目を意味ベースに判定し、利用者が登録したプロフィールを入力します。

**この公開リポジトリには、あらかじめ登録された個人プロフィール情報は含まれていません。**

## インストール

Tampermonkeyを導入済みのブラウザでは、次の公開UserScriptを開いてインストールできます。

**[UserScriptを直接インストール](https://raw.githubusercontent.com/hexahydroc-420/job-application-autofill-userscript/main/job-application-autofill.user.js)**

手動で導入する場合:

1. Tampermonkeyをブラウザへ導入します。
2. `job-application-autofill.user.js` をTampermonkeyへ登録します。
3. 対応する求人応募ページを開きます。
4. 画面上の「求人応募 入力支援」→「プロフィール設定」から自分の情報を登録します。
5. 内容を確認して「入力」を押します。

UserScriptには `@updateURL` と `@downloadURL` を設定しているため、公開版の更新先もこのリポジトリの `main` ブランチです。

## 特徴

- 氏名、連絡先、住所、生年月日などの基本情報
- 学歴・職歴・資格の複数登録
- 学歴・職歴・資格・企業独自回答のドラッグ / ↑↓ 並べ替え
- 複数プロフィールの作成・複製・切替・削除
- 職歴を先頭または末尾へ追加
- `select` / プルダウン、ラジオボタン、チェックボックス、複数選択への対応
- `role="radio"` / `role="checkbox"` / `role="switch"` / `role="option"` などのカスタムUI対応
- 資格取得年月、生年月日、学歴・職歴期間などの年月プルダウン入力
- 勤務希望地などの単一・複数選択
- 企業独自質問をGUIから追加
- プロフィール設定画面のリサイズ・最小化・最大化
- 入力支援パネルの移動・最小化・リサイズ・位置記憶
- 設定画面表示中の背面ページへのスクロール連鎖防止
- ファイル添付、同意、CAPTCHA、最終送信は自動化しない設計

## プライバシー

公開版には氏名、住所、メールアドレス、電話番号、学歴、職歴、資格、自己PRなどの個人プロフィール値を一切同梱していません。初回起動時のプロフィールは空です。

また、公開版は専用の保存キーを使用し、旧版・個人利用版の保存領域からプロフィールを自動移行しません。これにより、同じブラウザに個人利用版が存在していても、公開版が意図せず既存の個人情報を取り込まないようにしています。

プロフィールはTampermonkeyの `GM_setValue` / `GM_getValue` を利用してブラウザ側へ保存します。このUserScript自体には `fetch`、`XMLHttpRequest`、`GM_xmlhttpRequest` などの外部送信用APIは実装していません。

詳細は [PRIVACY.md](./PRIVACY.md) を参照してください。

## 安全上の仕様

以下は自動化しません。

- 応募の最終送信
- 個人情報保護方針や利用規約への同意
- CAPTCHA / reCAPTCHA
- 履歴書・職務経歴書などのローカルファイル選択

入力後は必ず内容を確認してください。

## 並べ替え

学歴、職歴、資格、企業独自回答は、カード右上のハンドルをドラッグして並べ替えできます。

上下ボタンでも移動でき、並べ替えハンドルにフォーカスした状態ではキーボードの上下キーも利用できます。保存した順序は次回起動時と応募フォーム入力時にも維持されます。

## 職歴の追加位置

職歴では、新しい経歴を追加する位置を選択できます。

- 先頭: 新しい経歴を職歴1として追加
- 末尾: 新しい経歴を最後へ追加

初期設定は「先頭」です。

## 開発・検証

公開化時に以下を確認しています。

- `node --check` によるJavaScript構文検証
- 個人情報に該当し得る既知文字列・メールアドレス・電話番号形式などの静的スキャン
- 公開版の初期プロフィールが空であること
- 旧版プロフィール保存キーから自動移行されないこと
- プロフィール設定画面が正常に起動すること
- 空の職歴へ項目を追加・保存できること
